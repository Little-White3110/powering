# 设置页精简与微调增强

## 已确认的决策
- 外观页删除「环缩放」（与「贴孔间隙」重叠：渲染公式 `(holeR+gap+stroke/2)×scale−stroke/2−holeR` 在 scale=1 时恰好等于 gap）
- 动效页折叠交互：功能关闭 → 子项自动收起，开启 → 自动展开

## 改动一：外观页去重（删「环缩放」+ 偏移精度细化）

1. `ui/SettingsScreen.kt:1350-1363` 删除「环缩放」滑杆。
2. `ui/ConfigJson.kt:45` 删导出字段、`:111-113` 删导入分支。旧文件里的 `ring_scale` 走"未知字段忽略"语义自动兼容，**schema 不升级**。
3. 遗留值迁移：`PrefsStore.kt` 新增一次性迁移（`SettingsActivity.onCreate` 调用）：prefs 里 `KEY_SCALE ≠ 1.0` 时重置为默认并走常规 commit+广播热加载，避免已无 UI 的值隐形生效。README 更新日志提一句"环缩放已移除，请用贴孔间隙重新校准"。
4. **保留不动**：`RingConfig.scale` 字段与 `RingRenderer` 公式（默认 1.0 兜底）、`ConfigProvider` 的 `KEY_SCALE`、`手动孔径`（自动定位失败机型唯一兜底）。
5. 顺带回应"dp 太大"：水平/垂直偏移吸附精度 1dp → **0.1dp**（UI transform、valueText 一位小数、`ConfigJson` 的 `offset_x/offset_y` snapped 由 `1f` 改 `10f`）。渲染侧本就按 float 消费，无需改。

## 改动二：滑杆微调能力（ConfigSlider 改造，`ui/SettingsScreen.kt:2058-2108`）

- `ConfigSlider` 新增 `step: Float` 参数；利用 miuix `SliderPreference` 的 `bottomAction` 槽位（已核实 0.9.4-rc01 存在）在滑杆下方放一行：`[−] 当前数值(点击可输入) [+]`。
- **步进按钮**：单击 = 一步并立即落盘（onCommit）；长按约 350ms 后每 100ms 连发（期间只 onChange 更新内存态），松手统一 onCommit 落盘。步进后经现有 `transform` 吸附 + `coerceIn(valueRange)`。随 `enabled` 置灰。
- **数值直接输入**：沿用 `ColorPickerDialog` 的 editing 模式——ConfigSlider 点击数值时向根级提升 `SliderEditRequest(title, value, valueText, range, precision, onCommit)`，SettingsScreen 根级（`:172-197` 一带）新增 `OverlayDialog` + miuix `TextField`（数字键盘）的 `SliderValueEditDialog`：解析失败/超范围时行内提示不关闭，确定时吸附+clamp+落盘。
- 保留 `touchGate` 防误触门控与 onChange/onCommit 两段式模式。
- 25 个调用点全部加 step（数值均为该项现有吸附精度）：贴孔间隙/环粗细/手动孔径/偏移X/偏移Y = 0.1；底槽浓度、亮度上限、发光强度、显示时长(0.1秒=100ms) 及动效页全部百分比/秒/BPM 项 = 1。
- `RangeColorRow`（电量区间双端滑杆）**不加**，整数步进已够用。

## 改动三：动效页折叠（`ui/SettingsScreen.kt:205-964`）

新增私有可复用容器（内部 `AnimatedVisibility` + `expandVertically/shrinkVertically` + 淡入淡出），包住各分组卡片中父开关之后的子项：

| 分组 | 折叠条件 | 说明 |
|---|---|---|
| 呼吸灯 | `!breathingEnabled` | 平时也呼吸/形式/颜色/速度 收起 |
| 消息提醒 | `!blinkOnNotification` | 子项整体收起（含两个轮询状态行，离场即停轮询） |
| 音乐律动 | `!musicPulseEnabled` | 同上 |
| 低电量特效 | `!lowBatteryTigaEnabled` | 触发电量/闪烁频率 收起 |
| 充电动画 | `chargingStyle == CHARGING_STYLE_PROGRESS` | 仅折叠动效子项（覆盖范围/整圈阈值/速度/幅度）；「动画颜色」保留常显 |

已有的组内条件渲染（节奏、整圈阈值的裸 `if`）保持不变。

## 明确不做（已排查、非重复）
- 底槽浓度(外观) vs 亮度上限(基础)：前者管底槽轨道可见度、后者是整体透明度上限钳制，语义不同，保留。
- 亮度上限 vs 发光强度(基础)：上限钳制 vs 光晕倍率，语义不同，保留（subtitle 理清表述）。
- `ConfigProvider`、`RingRenderer` 渲染公式、Hook 侧读取均不动；无 Hook 改动。

## 风险与兼容
- miuix `bottomAction` 槽位、`TextField` 用法均已从 0.9.4-rc01 元数据/现有代码核实。
- 曾调过环缩放的用户升级后环贴合度可能变化（一次性归零 + 更新日志说明），用贴孔间隙可重新校准。
- 遵守项目约定：仅 miuix 组件、不改跨进程配置方式、UI 字符串保持中文硬编码。
